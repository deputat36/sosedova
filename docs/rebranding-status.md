# Соседова Ипотека: аудит и состояние запуска

Дата: 13 сентября 2026 года. Репозиторий: только `deputat36/sosedova`.

## Что обнаружено

Исходный main содержал частично заменённую главную, но общие шаблоны, SEO-конфигурация, портреты и формы принадлежали предыдущему брокеру. Форма использовала прежний публичный ключ получателя Web3Forms. Существовали региональные страницы Борисоглебска, Грибановского района и Поворино, устаревшие утверждения о тарифах и работе с «ЭТАЖИ». Главная ссылалась на отсутствующее изображение Соседовой. Проверки CI были привязаны к фотографиям и географии предыдущего специалиста.

## Что сохранено и изменено

- Сохранены Jekyll, базовые CSS, адаптивное меню, JavaScript, отдельный ипотечный калькулятор, подробная анкета, consent validation, минимизация данных, защита localStorage и библиотека материалов.
- Личность, контакты, фото, преимущества, этапы, отзывы, социальные каналы и базовое SEO управляются через `_data/`. Шаблоны используют эти данные; front matter разрешает переменные через `_includes/resolve-meta.html`, поскольку Jekyll не исполняет Liquid внутри YAML.
- Главная раскрывает специалиста, опыт, услуги, этапы, FAQ, материалы и консультацию. Город Балашов указан в контактах и PostalAddress; areaServed — Россия.
- Все прежние содержательные страницы услуг сохранены. Добавлены квартиры, ИП, самозанятые и страхование; семейная ипотека дополнена. Общий шаблон добавляет этапы, FAQ и маршрут к форме.
- Старые локальные URL сохранены как HTML-перенаправления с canonical и noindex. Это не серверные HTTP 301: GitHub Pages не предоставляет собственные правила 301. В sitemap они исключены.
- Удалены чужие фотографии из публикации. До получения портрета используется монограмма. Отзывы не выдумываются: блок появляется только при заполнении `trust.reviews`.
- Старый Web3Forms-ключ удалён из текущей конфигурации. Форма работает в режиме подготовки текста и самостоятельной отправки SMS. Автоматическое получение заявок не подтверждено и не обещается.
- Социальные кнопки не выводятся с пустым адресом; появятся после заполнения `_data/social.yml`.

## Проверки

- GitHub Actions run 34773630573: source-audit и настоящая Jekyll-сборка с post-build tests — success.
- 128 собранных HTML-страниц: canonical, метаданные, H1, JSON-LD, внутренние ссылки, изображения, sitemap и отсутствие прежнего бренда проверены.
- Поведенческие тесты калькулятора, переноса расчёта в заявку, обязательного согласия и приватности атрибуции проходят.
- Chromium: 320, 390, 768, 1440 px; главная, каталог, семейная ипотека, форма, калькулятор, контакты. Проверены меню/Escape, отрицательная валидация формы, подготовка SMS, сброс устаревшего текста при редактировании, расчёт при нулевой ставке. Нет JS-ошибок и битых ресурсов.
- Скрипт `scripts/browser-smoke.cjs` запускает собственный loopback-сервер и блокирует все внешние запросы; реальные обращения не отправляются.
- Старые региональные, тарифные и фотографические post-build проверки заменены актуальной приёмкой `audit-broker-launch.py`. Функциональные проверки сохранены. Проверки неактивного backend разрешают безопасный режим `disabled`, сохраняя остальные требования.

## Не подтверждено

Доставка реальной заявки владельцу, идентификатор Метрики, ссылки социальных профилей, юридические реквизиты оператора и фактические условия услуг. Без этих сведений нельзя утверждать готовность к платной рекламе. Статус публичного домена проверяется отдельным production-smoke после публикации.
