# Сайт ипотечного брокера Людмилы Соседовой

Рабочий SEO и лидогенерирующий сайт проекта «Соседова Ипотека».

Домен проекта:

`https://sosedova-ipoteka.ru/`

## Цель проекта

Создать полноценный сайт ипотечного брокера:

- личный бренд Людмилы Соседовой;
- подбор ипотечных программ;
- консультации клиентов из любого региона России;
- SEO-продвижение услуг;
- получение обращений через формы, звонки и мессенджеры.

## Позиционирование

Людмила Соседова — ипотечный брокер с опытом более 15 лет.

Основные направления:

- подбор ипотеки;
- семейная ипотека;
- сельская ипотека;
- ипотека на строительство дома;
- покупка квартиры;
- сложные ипотечные ситуации;
- страхование.

## Текущий этап разработки

Проект развивается на основе технического шаблона ипотечного брокера.

Приоритеты:

1. Полная замена старого брендинга.
2. Подготовка продающей главной страницы.
3. Создание SEO-страниц услуг.
4. Настройка лидогенерации.
5. Добавление реальных материалов после получения информации от Людмилы Соседовой.

## Важно

Репозиторий `deputat36/broker` используется как исходная техническая база другого проекта и не изменяется.

Все изменения для Людмилы Соседовой выполняются только в этом репозитории.
